## Resumo dos Conceitos Praticados

Durante a realização dos desafios, foram praticados conceitos fundamentais de desenvolvimento de software e desenvolvimento web. Em HTML, foi trabalhada a estrutura básica de uma página, utilizando elementos e tags para organizar as informações de um currículo. Essa atividade ajudou a compreender como os elementos de uma página web são estruturados e organizados.

Na Linguagem C, foram estudados conceitos introdutórios da programação, principalmente a utilização de variáveis e a estrutura básica da linguagem. Uma das principais dificuldades foi compreender a sintaxe e a forma correta de organizar o código. Com a prática dos exercícios, foi possível desenvolver uma melhor compreensão da lógica de programação e da estrutura dos programas.

---

## Principais Conceitos Aprendidos

### HTML

- Estrutura básica de uma página HTML;
- Utilização de tags HTML;
- Organização do conteúdo de uma página;
- Criação de estruturas para um currículo;
- Hierarquia dos elementos HTML;
- Desenvolvimento da estrutura inicial de páginas web.

### Linguagem C

- Conceito de variáveis;
- Estrutura básica de um programa em C;
- Sintaxe da linguagem;
- Introdução à lógica de programação;
- Organização e execução de códigos;
- Primeiros passos na resolução de problemas utilizando programação.
